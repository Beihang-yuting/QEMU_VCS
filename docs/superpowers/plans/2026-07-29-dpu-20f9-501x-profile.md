# DPU 20f9:501x PCIe Configuration Profile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in `DPU_20F9_501X` VCS configuration-space profile supporting one to four PFs and sixteen VFs per PF, exact PF BAR/capability layout, functional PF MSI-X, topology-driven QEMU PF BARs, and unchanged legacy behavior.

**Architecture:** A pure SystemVerilog profile package owns profile selection, identity, BAR descriptors, and VF RID arithmetic. The existing UVM function/config managers consume the resolved profile and keep runtime configuration state, while the bridge transports resolved per-PF topology (including BAR flags) to QEMU. QEMU never parses the profile name; it validates the VCS topology and registers BAR0/BAR2/BAR4 for every PF.

**Tech Stack:** SystemVerilog/UVM 1.2, DPI-C, C11, QEMU PCI APIs, Icarus Verilog for pure-policy tests, Synopsys VCS for UVM/profile tests, CMake/CTest, Bash.

**Constraint:** Work only in the isolated worktree. Do not commit or push; replace commit steps with explicit diff/test checkpoints.

- [ ] **Step 3: Implement the minimal pure profile package**

Use these public names consistently:

```systemverilog
package pcie_tl_device_profile_pkg;
    typedef enum int {
        PCIE_CFG_PROFILE_LEGACY = 0,
        PCIE_CFG_PROFILE_DPU_20F9_501X = 1
    } pcie_cfg_profile_e;

    function automatic bit pcie_cfg_profile_parse(
        input string name, output pcie_cfg_profile_e profile);
        if (name == "" || name == "LEGACY") begin
            profile = PCIE_CFG_PROFILE_LEGACY;
            return 1;
        end
        if (name == "DPU_20F9_501X") begin
            profile = PCIE_CFG_PROFILE_DPU_20F9_501X;
            return 1;
        end
        profile = PCIE_CFG_PROFILE_LEGACY;
        return 0;
    endfunction

    function automatic bit [15:0] pcie_dpu_pf_device_id(input int pf);
        return 16'h5011 + pf;
    endfunction

    function automatic int pcie_dpu_first_vf_offset(input int num_pfs, input int pf);
        return num_pfs + pf * 15;
    endfunction

    function automatic longint unsigned pcie_dpu_bar_size(input bit is_vf, input int bar);
        if (!is_vf && bar == 0) return 32*1024*1024;
        if (!is_vf && (bar == 2 || bar == 4)) return 64*1024;
        if (is_vf && (bar == 0 || bar == 2)) return 16*1024;
        if (is_vf && bar == 4) return 32*1024;
        return 0;
    endfunction

    function automatic bit [31:0] pcie_dpu_bar_flags(input int bar);
        return (bar == 0 || bar == 2 || bar == 4) ? 32'h0000_000c : 0;
    endfunction

    function automatic bit [31:0] pcie_bar_sizing_dw(
        input longint unsigned size, input bit [31:0] flags, input bit upper);
        longint unsigned mask;
        if (size == 0) return 0;
        mask = ~(size - 1);
        return upper ? mask[63:32] : (mask[31:0] | flags);
    endfunction
endpackage
```

```c
    for (int bar = 0; bar < COSIM_MAX_BARS; bar++) {
        uint64_t size = pf->pf_bar_size[bar];
        if (!size) continue;
        s->bar_ctx[bar].dev = s;
        s->bar_ctx[bar].bar_index = bar;
        s->bar_ctx[bar].target_bdf =
            (pci_bus_num(pci_get_bus(dev)) << 8) | dev->devfn;
        memory_region_init_io(&s->bars[bar], OBJECT(s), &cosim_mmio_ops,
                              &s->bar_ctx[bar], "cosim-pf-bar", size);
        pci_register_bar(dev, bar, pf->pf_bar_flags[bar], &s->bars[bar]);
        s->num_bars++;
    }
    return s->num_bars > 0 ? 0 : -1;
}
```

PF0 uses topology entry zero. Each sibling uses `g_rc_pfs[0]->topology.pfs[pf_index]`.
Keep a legacy BAR0 discovery fallback only when no topology is available in a
legacy non-cosim flow.
